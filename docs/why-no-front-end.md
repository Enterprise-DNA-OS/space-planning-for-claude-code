# Why the planning desk has no front end

The recurring work is a space review: count assigned people, compare attendance with seats, test a move, chase owners and record a human decision. A database and coding agent can do that work directly. The read-only HTML files show results and print as review packs.

A screen gives useful things this base does not: drag-and-drop floor layouts, live badge and sensor feeds, desk booking, mobile check-in, offline forms and simultaneous visual planning. This base does not reproduce the full Accruent Space Intelligence platform or its forecasting methods. It keeps explicit peak-attendance assumptions separate from actual counts.

Use the free base when a planner can operate the records desk. Floor drawing interpretation and capacity approval stay with competent people. Omni by Enterprise DNA can scope a web view, live connections or mobile workflow around the business. Those are separate implementation work, not functions supplied by this repository.

Read-only views are declared in views.json. /new-view adds a question and verifies its answer. No action buttons, web server or OAuth service are needed for the demo.
